# ENIGMA LAB — 恩尼格玛交互检视终端

一个可直接运行、可继续迭代的 Enigma I 教学与三维检视网页。当前采用米黄色旧纸与复古器物陈列：木箱、黄铜转子、圆形胶木键帽和独立档案卡；加密逻辑遵循历史 Enigma I。支持中文 / English，语言选择保存在当前浏览器。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。开发服务只监听本机 `127.0.0.1`。生产构建：

```sh
npm test
npm run build
npm run preview
```

`dist/` 可部署到普通静态网站；源码、模型和加密均在浏览器运行，不需要数据库或后端。没有外部图片、模型、字体、音乐的运行时依赖。

## 发布网页

已包含 GitHub Pages 自动部署工作流：`.github/workflows/deploy.yml`。将本目录的内容作为 GitHub 仓库根目录，在 **Settings → Pages → Source** 选择 **GitHub Actions**，推送到 `main` 即自动测试、构建并发布。

完整操作步骤、仓库结构和常见问题见 [DEPLOYMENT.md](./DEPLOYMENT.md)。源码应在仓库根；工作流发布的是构建后的 `dist/`，不需要提交本地依赖或手动复制构建文件。

- 转子与反射器选中后的透明内部走线；线的端点来自与加密核心相同的历史接线表。
- Enigma I：I–V 五选三、B/C 反射器、独立窗口位置、01–26 环设置、最多 10 对常规插线。

- 11 阶段过程回放：机械步进、9 次元件映射、点灯。每个元件阶段默认 1.2 秒，阶段之间增加 0.85 秒的传导与机位衔接，均随倍速缩放；支持暂停、调速、单步、拖动与重复回放。暂停衔接时光点与镜头同时冻结。
- 可放大的 26 触点电路图；正向 / 返回分色，全部走线 / 当前路径切换，每步入口、出口和环偏移计算。

- 完整中英文切换：操作、配置、部件说明、帮助、教学计算与验证错误。
- 手机窄屏布局，以及 WebGL 不可用时保留电路与加密的降级提示。

## 全屏机器与控制窗格

机器、背景和阴影使用覆盖整个视口的三维画布。桌面端机器主要展示在左侧，右侧纸质窗格覆盖在画布之上，机身和阴影可延伸至窗格后方。设置和部件详情都在同一个已挂载的三维画布中更新，切换控制标签不会重新加载模型。

窗格提供四个标签：

- **检视**：部件索引、档案说明、电流观察，以及当前组件的局部拆解与零件隔离。
- **设置**：转子、窗口、环设置、反射器和插线的实时预览及应用。
- **操作**：虚拟键盘、实验记录、过程回放、单步和播放速度。
- **电文**：连续文本加密、明密文记录及复制。

桌面窗格宽度随视口调整为约 330–380 像素。宽度不超过 800 像素时，窗格移至底部并最多占用 42% 的视口高度，模型始终留在上方。滚动发生在窗格内部，三维和电路模式下都不会推动整页；电路图在独立纸面内滚动或展开。顶部语言切换、工作原理和项目说明保持可访问。

在模型上使用滚轮放大时，只有模型的屏幕投影接近展开窗格约 18 像素内，窗格才自动收起；小幅放大且仍有充足空间时保持展开。缩小时，模型与原窗格位置之间重新留出约 64 像素空隙后恢复，两个距离阈值避免在边缘反复开合。自动机位切换、设置预览和在窗格内滚动不会触发收起。

桌面窗格平滑向右退出，窄屏窗格向下退出，留下可直接操作的窄标签栏；展开使用反向滑入。移动过程中保持原内容宽高，文字不会因窗格变窄而重新换行，已收起的表单退出键盘焦点顺序。也可点击箭头手动收起，或点击箭头及标签展开；手动收起的窗格不会因缩小模型而自动展开。窗格开合保持机器的位置与当前缩放距离，避免为让位而突然平移模型。

## 电路剖面与视图切换

三维检视与电路剖面共用固定工作台和相同位置的模式入口、导航与控制窗格。两种视图持续挂载，以短渐变切换；切换不重置组件检视、相机、记录、电路缩放、走线开关或图内滚动。电路模式的右侧窗格显示档案与电流控制，返回三维会恢复先前的机械组件控制。

电路采用米色网格纸，顶部显示本次信号、窗口和环设置；11 个阶段可直接定位，琥珀色表示正向、青绿色表示返回。触点字母与当前元件加深显示，支持 50%–200% 缩放、适配、独立图内滚动与展开。展开后的图面覆盖窗格，Esc 收起并恢复按钮焦点。顶部摘要与阶段条吸顶，图内放大与触点浏览不推动整个页面。

整机与外壳详情均使用相同的木箱和紧固结构，保留前角锁扣，不设侧拉环。

## Enigma I 外壳与面板结构

本轮参照 [Crypto Museum 的 Enigma I 资料](https://www.cryptomuseum.com/crypto/enigma/i/index.htm)，调整了机体装配关系：木质运输箱与内部空心金属机架分开，顶板的转子井、灯板区和键盘区都有实际开孔；转子、灯具及按键杆从对应空间安装，避免直接穿过实心盖板。合罩时保留三个转子读数窗和拨轮槽。

整机转子刻度环上的 **01–26 数字随转子实际旋转**，通过窗口读取，不是另贴在顶盖上的静态数字。设置与信号教学仍使用 A–Z，按 A＝01、B＝02、…、Z＝26 对应；环设置继续使用 01–26，加密索引与步进规则不变。

灯板采用接近平齐的黑色字母片和细压边，26 个扁平灯泡、灯座与绝缘件放在下方；键盘导板有 26 个贯穿孔和空心导套，按键杆保留运动间隙。内部接线、跟随电流回放及转子／反射器检视时，罩壳自动剖开以便观察；这是教学展示动作，不表示实物会在通电时自动开罩。

“操作”窗格顶部的“机械展示”提供两个独立开关：**移开／装回转子护罩**，欣赏实体转子和机械结构；**移开／装回灯板盖板**，观察灯泡、灯座及其下方接线。按钮支持中英文并显示各自状态，切换时返回三维整机。开关不修改加密配置、当前窗口、信号轨迹或实验记录，也不停止正在进行的回放。操作转子护罩时回到实体整机，关闭跟随电流、透明接线和整机展开，确保装回和移开的结果清楚可见；需要时可重新开启这些教学选项。灯板盖板独立控制，26根灯引线和端子位于下方，输出对应的灯泡和引线同时亮起；布线路径属于教学示意。

资料核查覆盖金属机架与木箱的区别、顶盖窗口、数字刻度环、三行 26 灯、顶盖内的字母薄片及前翻板。当前比例和空间布置为参考照片与结构说明制作的教学建模，**不是原厂测绘、实物扫描或制造尺寸复刻**；导线弯曲、剖切动作与部分安装细节仍为示意。资料依据与参考图片链接见 [RESEARCH.md](./RESEARCH.md#enigma-i-外壳与灯板资料核查)。

## 三维接线演示（本轮重点）

点击“检视”窗格中的“载入接线演示”，页面加载 I–II–III / B / 初始 AAA / 环 01–03–06 / 插线 AB CD EF，并对字母 A 生成一次完整的真实轨迹。该操作会替换当前实验设置和记录，演示初始暂停在插线板 A → B。

用“检视”窗格档案卡中的前进/后退或阶段进度条逐段查看（窄屏时窗格覆盖在视口底部）：

1. 插线板：A → B 的实际连接线。
2. 右转子 III：外部 B → W，线芯 X → S（窗口 B、环 06）。
3. 中转子 II：外部 W → R，线芯 U → P（窗口 A、环 03）。
4. 左转子 I：R → U。
5. 反射器 B：U ↔ C。
6. 左转子返回：C → Y，沿物理 Y → C 导线反向移动。
7. 中转子返回：外部 Y → O，线芯 W → M，沿物理 M → W 反向移动。
8. 右转子返回：外部 O → Y，线芯 K → U，沿物理 U → K 反向移动。
9. 插线板：未连接的 Y 直通 Y，点亮 Y。

“内部接线”开关持续显示所有内部线，并按当前电流阶段切换观察部件；即使关闭该开关，正在通电的元件也会自动剖开以显示当前导线。暂停或单步时高亮保持，可拖动观察。琥珀色为正向，青绿色为返回。

顶部“机器设置”展开密钥配置。复位恢复真正应用过的初始配置。继续播放一个手动选中的阶段时，会从该阶段导线起点开始；重复回放不会再次推进加密状态。

“跟随电流”默认开启：镜头在衔接阶段平滑移动到下一枚转子或部件；阶段内可自由拖动。点击部件索引会退出跟随，重新打开开关可恢复。单步前进播放衔接后暂停在下一段的完整导线上；后退或从末尾返回开头只转换镜头，不伪造倒流。拖动进度直接定位。虚线表示跨部件的教学示意连接，转子之间的短连接使用真实触点。

## 从整机进入部件详情（最新）

直接点击整机上的具体转子、反射器、插线板、按键区或外壳，即可在同一个三维画布中进入对应部件详情。点击哪一枚转子，就检视该槽位实际安装的型号、窗口和环设置。反射器同样进入独立组件检视，灯板保留整机近景。页面不再提供独立机械检视入口；详情始终从当前机器进入，保留米黄旧纸、黄铜、木材和胶木风格，中英文同步切换。

详情包含六类结构：

1. **转子解剖**：字母环与缺口、真实 26 根线芯导线、52 个接点、两侧触点板、空心倒角端盖、棘轮、轴心与定位销。
2. **双针插头**：圆角胶木握柄、防滑纹、双金属插针、贯穿插孔、绝缘衬套、后侧扁平弹性触片、线尾防折套。
3. **按键与回位**：圆形字母键帽、推杆与导套、螺旋弹簧、摇臂、绝缘滚轮、动静触点。按下和释放时，共用几何关系保持推杆与摇臂、滚轮与触片对齐。
4. **外壳与五金**：带倒角木箱、金属底盘及开孔盖板、箱盖与内衬、合页和抽离轴销、锁扣、螺钉与垫圈。
5. **步进机构**：从转子或按键详情中的关联按钮进入，检视 26 齿非对称棘轮、棘爪、回位弹簧、公共摆架、连杆、轴承及紧固件。
6. **反射器解剖**：从正面查看 26 位胶木触点盘、黄铜边圈、13 对固定接线、黄铜背盖、定位轴套和紧固件。默认小幅展开，逐对选择高亮导线及两个端子；支持零件隔离和连续拆解，读取当前 UKW B/C 配置。绕轴的分层走线用于结构教学，真实配对直接读取加密核心。

拖动“拆解间距”可连续分离当前组件的零件；“合拢 / 展开”带平滑过渡。点击模型零件或零件索引可隔离对应零件组，镜头平滑聚焦。路径栏可返回“完整组件”或“整机”，按 Esc 也可返回。旋转与缩放继续作用于当前检视对象，可以从侧面和底部观察结构。

步进机构和按键都可播放、暂停、拖动进度和复位。步进机构提供当前设置、右轮步进、缺口进位和双步进示例；推进决策直接取自已验证的 `encryptKey`。棘轮在推进段准确转一齿，连杆回位时棘轮保持新位置。`AEW → BFX` 是连续双步进中的后一击；不是一次演示重复加密两个字母。

转子详情读取所点击槽位的当前安装型号、窗口和环设置。选择 A–Z 中任意线芯入口可突出显示其固定配对。这里标注的是**线芯坐标**，与整机电流检视中的外部触点坐标有明确区分。字母环与缺口随窗口角度，线芯、触点板和驱动棘轮随窗口减环设置的角度。透明外罩开关在任何拆解间距下都可使用。

进入详情会暂停主电流回放；机械演示仅改变局部演示进度，不推进主机器，也不增加密文或实验记录。返回整机保留之前的配置和记录。显式执行加密、主过程回放或设置预览时，页面退出部件详情并返回整机模型，显示对应的电气过程或配置变化。

已修复返回整机时转子比机身晚出现的问题：根因是淡入淡出将实体材质移入透明绘制队列并改变深度关系，导致嵌套转子在过渡中被错误遮挡。现在过渡保留各材质原有的深度写入和透明策略，实体使用透明度散列完成淡入淡出；整机与详情统一使用 0.55 秒过渡，结束后恢复原材质状态。

本轮是可逐件查看的程序化结构模型，尚未将整机的每枚螺钉做成可自由拖放、逐步装配的系统。插头提供拆解观察，未模拟插入深度引起的常闭触片开关动作；棘爪啮合、弹簧力与连杆尺寸仍属于教学示意。后续可在稳定部件分组上替换实物测绘 glTF，再增加装配约束。

## 模型中的信号标注

整机电流回放、设置预览与环检视共用无底的悬浮文字，去掉原来的浅色方框和描边卡片。当前部件上方保留简洁映射；触点附近显示信号色的外部字母，下面用小字说明线芯坐标，细引线对应实际接点。正向用琥珀色，返回用青绿色；背景上的标题用深墨色，覆盖深色机身的文字用暖米色，字形边缘仅保留细轮廓以保证可读性。

端点文字按物理接点面向外偏移，因此回程和反射器不会因输入／输出顺序反转而挤入组件内部。插线板直通时，两端光点和原电路保留，只显示一份端点字母与“直通”；历史路径不累积标签。窗口、缺口和线芯 A 使用短标注，环实验中与活动 A 重复的外部基准字会隐藏。

标注使用原生 WebGL 透明文字纹理，不拦截模型点击，随对应组件的进入／退出过渡显示。转子本身的历史刻字继续保留；动态教学字与实体刻印分开，避免把随环和窗口变化的外部字母误当作固定线芯编号。

## 环设置 · 信号实验

在转子详情中，选择当前安装的左／中／右转子，直接使用“环设置 · 信号实验”。固定窗口位置和外部输入，改变 01–26 的试验环设置；支持下拉、逐格加减与拖动，26／01 之间连续循环。模型中的窗口与字母环保持不动，线芯、触点板及棘轮按“窗口 − 环”的偏移平滑旋转。紫色“线芯 A”随线芯移动；两侧外部参考触点和窗口指针保持固定。

“展开观察”分离组件并打开内部接线。直接检视“字母环与缺口”时，会保留相连的线芯和触点板，便于比较相对角度。固定输入接到的真实线芯导线及外部出口同步高亮；四段路径分别标明 **外部输入 → 线芯入口 → 固定线出口 → 外部输出**，区分外部与线芯坐标。转动途中暂时隐藏通电路径，完成对位后再显示新映射，避免形成接点未对齐时已经导通的错觉。

右侧同时显示实际环设置和试验环设置的单转子出口，并可展开“对照一次整机按键”：它从相同起始窗口分别调用真实加密引擎，先步进，再走完插线板、三枚转子和反射器的往返路径。例如默认 AAA、I–II–III、无插线时，右转子固定窗口 A、固定输入 A，环 01 的单转子映射为 A→A→B→B；改环 02 后为 A→Z→O→P。独立整机按键对照的灯号则分别为 B、U，因为整机按键包含步进和完整电路。

本地试验不会提交机器设置、推进实际窗口或增加实验记录。“恢复实际环设置”回到安装值；换槽位时试验环也恢复该槽位的安装值。关闭实验可以继续逐根选择固定线芯导线。中英文界面与三维标牌同步切换。

外部参考圈、连接引线和小标牌是教学辅助，不是新增的实体机械零件。环设置改变固定窗口下的电气映射，不改变字母环上的缺口位置；相同起始窗口的步进决定和双步进保持一致。

## 设置实时预览

打开顶部“机器设置”或窗格的“设置”标签，调整下拉框后模型立即预览，不必先点击应用。设置在覆盖于机器背景之上的窗格内滚动；窄屏时窗格位于底部，调整参数无需整页上下滚动。

- **窗口**：字母环与线芯一起平滑转动，固定指针对应新的窗口字母。
- **环设置**：字母环和窗口保持不动，线芯相对转动；紫色“线芯 A”基准点可直观看出变化。偏移显示为窗口的零基值减去环的零基值。
- **型号**：对应的 26 条固定内部接线、型号标识与缺口位置同步更换。选中另一槽位已安装的型号时，两槽位交换型号，槽位的窗口和环保持不变。
- **反射器**：切换 B/C 时显示对应的 13 对连接；反射器本身固定不旋转。
- 预览轮会自动近景透视，另外补有字母环刻度、固定窗口指针、轴心与螺钉、线芯基准点、缺口标记。缺口标记不等于完整棘爪仿真。

预览暂停旧回放并保留密文/实验记录；旧电流不会叠在新草稿模型上。应用才提交设置、复位与清空记录；取消会回到之前已应用的机器状态与旧轨迹。输入未完成或无效插线时，预览保留上一次已应用的插线，其他机械参数仍可调整；应用时执行完整校验。

此轮不需要额外建模工具，模型与动画都由现有 Three.js 程序生成。后续提升到实物级外观时，可用 Blender 制作高精度倒角、磨损贴图和机械部件，导出分层 glTF；真实接线、状态和运动仍由当前密码内核驱动。

## 设置插线板

点击整机或部件索引中的“插线板”，在组件详情底部选择“设置插线配对”，再在档案卡输入 `AZ`，点击“连接并复位”（或按 Enter）。看到“当前连接：A ↔ Z”后，三维模型立即显示这根跨行电缆。多对用空格分隔，如 `AZ BY CX`；留空并应用可拔除全部插线。顶部“机器设置”中的插线输入也可使用。

原问题是暂停在阶段 0–9 仍被判为忙碌，导致应用按钮禁用；现已允许在播放、暂停及步骤衔接中应用新配置。应用会停止旧回放、恢复初始窗口并清空记录。档案卡快速连接只修改插线，保留其他已应用设置；顶部应用按钮会提交整份配置。无效或冲突配对会就地提示，保持原配置。

注意：`AZ` 表示插线板内部 A ↔ Z，整机仍经过转子与反射器，不保证最终灯号为 Z。I–II–III / B / 初始 AAA / 环 01–01–01 / 插线 AZ 时，输入 A 的第一段为 A → Z，最终灯号 U；复位后输入 Z，第一段 Z → A，最终 B；复位后输入 U，最后一段 Z → A，最终 A。

## 外部字母与线芯字母为何不同

三维端点现在以**外部触点字母**作为主标签，并用副标签明确标出“线芯”。转子上方同时显示外部映射、固定线芯导线、当前窗口和环设置；右侧四格换算与模型使用同一条加密轨迹，中英文同步切换。

例如 I–II–III / B / 初始 AAA / 环 01–01–01 / 插线 AZ，按下 A 后插线板送出 Z，右转子先转到 B，偏移为 +1：

**外部 Z →（+1）线芯 A →（III 固定接线）线芯 B →（−1）外部 A。**

所以外部 `Z → A` 与线芯 `A → B` 是同一次传导在两个坐标系下的表示。原先三维端点只写了线芯 A/B，没有说明坐标类型，容易与外部映射混淆；本次修改了标注和教学解释，真实固定导线及旋转计算保持正确。返回时使用同一根导线的逆向遍历，例如外部 A → Z 对应线芯 B → A。字母换算按 A–Z 循环，偏移按零基窗口减零基环设置计算。

## 第一轮验收路径

1. 保持默认 I–II–III、窗口 AAA、环 01–01–01、UKW B、无插线，点击按键 A：输出 B，右转子转到 B。
2. 暂停并选择“电路剖面”，点击“放大电路”。逐步查看 A → A → C → D → F → S → S → E → B → B 的触点路径。
3. 复位后，在电文实验中输入 `HELLOWORLD`，输出应为 `ILBDA AMTAZ`。
4. 再复位，输入 `ILBDAAMTAZ`，输出应为 `HELLO WORLD`。
5. 在“工作原理”载入双步进示例；连续输入三个字母，窗口应为 `ADU → ADV → AEW → BFX`。
6. 修改环设置 / 插线后应用，检查电路连线变化。`AB AC` 应提示同一字母不能重复连接。
7. 点击某一槽位的转子进入详情，核对型号与窗口；局部拆解、隔离零件，再通过路径栏或 Esc 返回。查看插头、按键、外壳以及关联步进机构；反射器支持独立组件解剖，灯板保持近景检视。重复回放后确认密文与窗口不额外变化。
8. 切换 中文 / EN，检查说明与控制都对应切换；刷新后保持语言选择。

机器仅处理字母。电文输入允许空格与换行并忽略它们，其他字符会提示错误。批量输入从**当前**窗口继续，解密前必须复位到原始配置。每次批量最多 500 字母。

## 正确性验证

当前自动化测试套件 **253 项测试全部通过**：

- 12 项安装几何测试：26 个灯孔和键杆导孔实际贯穿面板、转子井净空、三枚拨轮完整旋转包络避让护罩、窗口读数视线、相邻编号遮挡、数字环整周包络、窗框互不相交、灯环互不重叠，以及26盏灯在整机与近景机位不被护罩遮挡。
- 12 项环设置实验测试：单转子探针覆盖五种转子的全部 26 窗口 × 26 环 × 26 输入，共 87,880 个组合；同时验证 III/B/01 的 Z→A→B→A 已知路径、环回绕、三个槽位的整机对照、双步进不受环影响，以及原配置和记录不变。
- 6 项场景过渡测试：实体深度顺序、原生透明材质、转子材质替换、共享材质透明度、隐藏对象交互，以及反复进入和退出后的状态恢复。
- 17 项全屏取景与缩放测试：桌面右侧和窄屏底部预留空间、响应式窗格边界、极小视口安全取景、用户缩放识别、18/64 像素避让迟滞、模型与窗格的实际间距，以及排除自动机位变化。
- 3 项投影轮廓测试：斜视角下分别计算网格轮廓以排除空角，忽略隐藏零件和阴影辅助面，以及正确更新相机与模型变换。
- 5 项机械动作测试：真实加密核心生成普通步进、缺口进位、中轮双步进、Z→A 跨越状态；逐帧验证一齿总量、未推进轮静止、回位无倒转、角度跨周连续，以及越界进度裁剪。

- 7 项设置预览测试：型号交换、槽位环与窗口保持、未完成插线、参数验证、草稿与已应用配置隔离，以及旧轨迹不变。
- 4 项 AZ 回归测试：独立完整触点轨迹 A → U、Z → B、U → A，以及更改/清空配对后的密文与历史快照隔离。
- 49 项内核测试：标准向量、双步进、五种缺口、环设置、插线验证、往返逆置换、不映射自身、不修改输入对象、完整历史陆军电报等。
- 17 项三维路径测试：覆盖五种转子 × 26 个窗口 × 26 个环设置，共 3,380 次完整轨迹，验证真实线芯导线、回程方向与旋转后的固定触点对齐；另对 III 转子外部 Z → A / 线芯 A → B 及同线回程分别回归验证。反射器新增 B/C 全部配对的平滑曲线采样，验证正反向同线、触点端点以及含高亮半径的轴心与外壳间隙。
- 121 项独立参考测试：固定版本 **Py-Enigma 1.0.2** 实际运行生成参考结果，覆盖全部 60 种不重复转子排列 × B/C 反射器，共 **120 种配置**。
- 对照 **105,240 个字母**和 **4,851 个中间窗口状态**，含非零环、0–10 对插线、190 次中间转子连续步进，全部一致。

## 精度边界

此版本已对**电气置换、步进逻辑和过程轨迹**进行独立验证。三维模型是参考历史照片与结构资料的原创教学模型，并非原厂测绘、实物扫描或制造尺寸复刻。

- 26 条走线的**电气端点**准确，但空间弯曲形状是示意，不代表某台实物的导线铺设。
- 三维电流直接绑定真实字母触点：插线板高亮实际配对，转子高亮本次所走的线芯导线，反射器高亮固定配对，回程沿同一物理导线反向移动。导线弯曲、部件间连接的空间布置仍是教学示意。
- 元件内部与转子间触点桥都有传导动画。按键到插线板、插线板到输入轮及返回灯板的路径以带光点的虚线桥衔接；这些长路径是明确标注的教学示意，完整历史线束尚未复原。
- 按键连杆、棘爪、弹簧、缺口啮合等尚未构成完整刚体机械仿真；反射器、插孔、字母环等机械尺寸也未按测绘校准。
- 输出灯与按键状态保留为最后一次闭合电路的教学快照；回放不执行第二次加密。
- 当前按常规战时设置限制 10 对插线；实体插线板理论上可插 13 对。
- 暂未包含 M4、海军转子 VI–VIII、可接线反射器 D 等其他制式。
